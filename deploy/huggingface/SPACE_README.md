# YieldSense AI

Crop yield prediction and agricultural productivity intelligence: an XGBoost yield model with a P10–P90 range, weather and real soil data, recommendations, risk assessment and analytics, for farmers, agronomists and administrators.

This Space runs the whole application in one container (Nginx + FastAPI). PostgreSQL (Neon) and MongoDB (MongoDB Atlas) are external free services configured through Space secrets.

Demo accounts: `farmer / farmer123`, `agronomist / agro123`, `admin / admin123`.

Source code and documentation: see the project repository.
